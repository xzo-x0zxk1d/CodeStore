# كود ستور — تعليمات تشغيل وتوصيل Stripe

ملخص:
- مشروع صغير مُعد لبيع أكواد (نماذج) باسم "كود ستور".
- صفحة أمامية بالعربية، Checkout عبر Stripe، صفحة إيصال تطلب أخذ لقطة شاشة، وروابط تنزيل بعد الدفع.

ملفات هامة:
- `server.js` — خادم Express ويحتوي على نقاط النهاية:
  - `GET /products` — قائمة المنتجات
  - `POST /create-checkout-session` — إنشاء جلسة Stripe Checkout
  - `GET /session?session_id=...` — استعلام عن الجلسة وتسجيل البيع
  - `GET /download/:file?session_id=...` — تنزيل الملف بعد التحقق
  - `GET /top-sales` — إرجاع العناصر الأكثر مبيعًا
- `products.json` — المنتجات الموجودة للبيع
- `downloads/` — ملفات قابلة للتنزيل (عناصر نضع بها الكود الفعلي لاحقًا)

إعداد Stripe (خطوات سريعة):
1. سجّل دخولك إلى Stripe واذهب إلى Dashboard > Developers > API keys.
2. انسخ `Publishable key` و `Secret key` وضعهم في المتغيرات البيئية على جهازك:

   Windows PowerShell:
```
$env:STRIPE_SECRET_KEY = "sk_live_..."
$env:STRIPE_PUBLISHABLE_KEY = "pk_live_..."
```

3. (اختياري لميزة Apple Pay) قم بإثبات ملكية الدومين في Stripe Dashboard > Settings > Payments > Apple Pay. ستحتاج رفع ملف HTML تأكيد إلى المسار /.well-known/apple-developer-merchantid-domain-association على موقعك الحقيقي.

ملاحظة مهمة حول الاستلامات / الحوالات:
- Stripe يجمّع المدفوعات ثم يحوّلها إلى الحساب البنكي أو وسيلة استلام مرتبطة بحساب Stripe الخاص بك. لا يمكن للمشروع مباشرة إرسال الأموال إلى بطاقة ائتمان شخصية أو رقم STC Pay من خلال الكود. قُم بإعداد حساب Stripe وربطه بحسابك البنكي أو طريقة السحب المتاحة في بلدك.

تشغيل محليًا:
1. افتح مجلد المشروع في VS Code (`c:\Users\xzo\Desktop\app`).
2. ثبت الحزم:
```powershell
npm install
```
3. شغّل الخادم:
```powershell
npm start
```
4. افتح المتصفح على `http://localhost:3000`.

ملاحظات أمان:
- هذا مشروع نموذج/بروتوتايب. لا تعتمده في الإنتاج بلا مراجعة أمنية.
- استخدم Webhook للتحقق الحقيقي من المدفوعات بدلاً من الاعتماد على إعادة التوجيه فقط.

تخصيص:
- لتعديل الملفات التي يتلقاها المشتري، استبدل محتوى الملفات في `downloads/` بالمحتوى الفعلي.
- لتغيير الأسعار أو إضافة منتجات، عدّل `products.json` ثم أعد تشغيل الخادم.

إذا رغبت أستطيع الآن:
- تشغيل `npm install` وبدء الخادم (سأحتاج إذناً لتشغيل أوامر على جهازك)،
- أو أضيف تسجيل Webhook آمن لتأكيد الدفع قبل إصدار التنزيلات.
